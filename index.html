操作说明

如何播放

  • 本地文件：菜单「文件」→「打开文件」，选择 mp4、flv、webm 等视频。
  • 网络地址：菜单「文件」→「打开网络地址」，输入 URL 后点确定。
  • 播放控制：底部栏可播放/暂停、拖动进度、调节音量与倍速、全屏。
  • 全屏：点击底部全屏按钮，或菜单「视图」→「全屏」；按 Esc 或再点一次可退出。

支持的格式

  • 本地 / HTTP：MP4、WebM、MOV 等常见格式。
  • HLS：.m3u8 地址（如 https://example.com/live.m3u8）。
  • FLV / MPEG-TS：http(s) 或 ws(s) 上的 .flv、.ts 直播流。
  • WebSocket：ws:// 或 wss:// 的 FLV 实时流。
  • RTSP / RTMP：rtsp://、rtmp:// 地址（程序内置 FFmpeg 自动转 FLV 播放，无需单独安装）。

说明

RTSP/RTMP 需本机可访问该流地址；国外演示源在国内可能无法连接。调试时可打开「视图」→「开发者工具」查看日志。
